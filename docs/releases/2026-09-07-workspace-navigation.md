# 2026-09-07 工作区导航与加载优化

本批次以一个提交推送到 `main`，解决本地试用中发现的切页认证闪屏、导航状态不明显、宽屏内容过窄以及注册中心首次加载偏重的问题。

## 包含功能

- 后台刷新登录状态时保持当前页面和未保存输入；初次认证、认证失败、会话过期仍执行原有保护。登录页等待当前校验完成后再跳转，防止使用过期缓存误入应用。
- 能力中心品牌图标使用蓝色，主导航和管理员导航的选中项采用浅蓝背景与蓝色文字/图标；移动侧栏同步。
- 工作区随窗口宽度展开，能力卡片按容器宽度自动增减列数；设置表单等区域保留适合阅读的宽度。
- 将七个菜单从共享动态入口拆成独立页面，URL 保持不变；增加路由加载状态。注册中心 First Load JS 从约 286 kB 降至 129 kB，该指标不等同于真实接口或页面耗时。

## 清理与本地文件

删除被独立页面替代的 `[section]` 入口；移除本轮重复及已被后续布局替代的四张截图，保留必要截图和可复现检查脚本。未清理历史数据库迁移、运行中的服务缓存或用户依赖备份。

本地自测手册、Skill 示例材料和启动脚本通过本地排除规则或已有缓存目录规则保留，不进入提交。启动脚本的文件轮询及页面预热仅在用户本地生效，不是本次仓库交付的功能。
