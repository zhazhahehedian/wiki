# 2026-10-27 飞书目录、发布 API 与部署整合

本批次汇总已部署到 [Capability Hub](https://hub.sn0w.icu) 的工作区改动，包括此前保留的部署、模型适配、落地页、操作指南和登录修复。运行版本为 `20261027-directory-api-root`；提交源码不触发再次部署。

## 功能

- 当前登录人可见的飞书部门和人员选择，复用 OAuth 令牌加密与刷新，关联保存飞书 ID。目录可见范围与真实部门归属独立校验；根组织不可见时，仅展示使用当前用户令牌逐个核验的本人部门入口。
- MCP / Skill 注册、更新、上传、新版本草稿和提交审核 API；账号绑定的凭证支持 scope、到期和撤销，只保存摘要。沿用 Owner/Admin、审核与原子发布规则，提供站内接口文档、调用示例和凭证管理。
- 百炼原生文本 embedding 适配、1024 维校验与输入预算；DeepSeek 优化接口适配及否定/限制条件保护。未更换现有知识数据的向量维度。
- 应用与 Caddy HTTPS 的 Compose 配置、生产镜像构建和独立迁移入口，复用外部 PostgreSQL/MinIO。
- 公开落地页、操作指南、工作台入口；飞书登录成功后直接进入 `/hub`。
