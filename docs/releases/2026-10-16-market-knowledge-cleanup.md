# 2026-10-16 内部市场、K1 知识服务与旧代码清理

本批次从本地 `main` 推送，包含以下功能和清理：

## 功能

- **内部能力市场**（`4c3bc0e`）：授权上线目录、独立上线详情、正文/附件预览与下载；可把已上线的 Skill 复制为自己的草稿。
- **K1 知识服务**（`4c3bc0e`、`1ed9cfb`）：
  - 知识库与文档管理，支持 TXT/Markdown/DOCX/文字型 PDF，解析时严格校验并提供预览与诊断。
  - River 异步版本索引、权限过滤检索、应用凭证与授权。
  - Bearer 检索 API `POST /api/v1/knowledge/search`，可选问题改写、混合召回与重排。
  - 迁移 0016/0017；页面在 `/hub/knowledge`。

## 修复与简化

- **游乐场 / Skill 创建**（`420cfcd`、`9bc1b8d`）：
  - 默认输出上限改为 8192，最大值 131072（原默认 65536 超过多数模型上限）。
  - 上游错误合并为 4 类提示；超时只保留服务内一层。
  - 复制 Skill 不再每次多出一个空行。
- **知识服务后端**（`1ed9cfb`）：
  - 去掉串行全部写操作的全局锁，改用行级锁；文档片段一次批量写入。
  - 检索审计与实际响应一致；只有关键词命中、未经模型重排确认的片段不返回。
  - 每次检索的权限复核由最多 4 轮降为 2–3 轮。
  - 未配置 `EMBEDDING_*` 时知识模块不装配，相关接口返回 404。
- **前端**（`4225d9b`、`5f6442a`）：
  - 应用授权了已取消共享的库后可以移除并保存。
  - 文档列表只在有文档处理中时轮询。
  - 知识页拆分为多个文件并改用 `useMutation`；市场详情显示发布者名称。
