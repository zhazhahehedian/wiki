# K1 单次问题检索优化验证

## 实现范围

原问题保留 + 可选模型改写，原问题/改写问题向量召回 + 中文双字词/拉丁词关键词召回，RRF 去重融合 + 词项覆盖基础重排 + 可选模型相关性重排。模型只能评分授权活动版本候选，不生成答案或修改引用。参数、默认阈值和限制见 [API 文档](../../knowledge-api.md)。

无新依赖、无新迁移、无需重建旧索引。查询 SQL 位于 repo，活动版本复核使用新 sqlc 批量查询及生成代码，避免对扩大候选逐条往返数据库。保留全部既有工作区变更和知识数据，不提交、推送、部署或迁移业务库。

## 真实基础设施与模拟模型边界

沿用本会话用户授权，`TestKnowledgeCloudIntegration` 创建随机隔离 PostgreSQL 库，在远程 MinIO 写入并清理随机对象；不作用于业务库。已验证迁移 15→17→15→17，River 发布与中文关键词 SQL；向量 fixture 无法命中的“发票”由关键词召回，活动版本引用保持，其他库候选隔离，无关问题返回空。模型端点使用本地 HTTP fixture，仅验证协议接线，不能证明语义准确率。

完整联调通过（583.34 秒），覆盖 API 授权/scope/凭证、旧版本保留、并发版本切换、删除/撤权及应用授权清理。期间远程延迟较高，River 领导者退出曾记录两次超时重试，最终测试与清理成功；这不能作为试用性能达标证据。后续版本复核批量化及无模型时减少一次冗余复核，已通过相关 race/vet/build；新增定向远程查询验证跟踪如下。

`TestKnowledgeActiveDocumentsCloud` 通过（20.29 秒），只在另一个随机隔离库创建最小测试表，验证实际生成 SQL 能批量读取最新活动版本，排除已删除文档/库和范围外知识库；测试后成功删除该库。这是查询验证，完整迁移验证由上述联合测试承担。临时前端服务、浏览器与截图脚本已停止/清理，截图作为 fixture 证据保留。
