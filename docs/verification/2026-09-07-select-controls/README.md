# 下拉控件统一验证

2026-09-07。模型配置的原生下拉展开后采用系统样式，与工作区不协调。本次沿用已安装的 Base UI，新增共享 Select，将模型配置、游乐场、Skill 创建和能力管理中的 13 个原生选择控件统一为白底、细边框、浅蓝选中态和勾选图标。未新增依赖。

保留字段标签、键盘操作、禁用状态、表单值和空字符串筛选语义。长模型 ID 在触发器中省略、列表中换行，并限制配置表单最小宽度，避免移动端弹窗被长 ID 撑宽。

## 验证

- `pnpm test`：37 个文件、160 项测试通过。包含新增选择控件键盘/焦点/空值/禁用回归，以及修改后的协议切换、模型保存、对话、能力编辑和 Skill 创建测试。
- `pnpm typecheck`：通过；最终 `pnpm build`：通过，包含类型检查。
- `browser-check.cjs`：生产构建下运行 Playwright 1.58.2，覆盖弹窗内下拉层级、Escape 返回焦点且保留父弹窗、切换协议保留自定义中转地址、获取模型、选择默认模型并保存、选中模型发送模拟流式消息、能力类型/鉴权/可见范围、Skill 创建方式/模型、状态筛选重置。
- 桌面 1440×1000、移动端 390×844：弹层在视口内、长 ID 可换行、配置弹窗无横向溢出；无页面脚本异常。截图见本目录，检查结果见 `result.json`。

浏览器拦截全部业务 API，域名、密钥和模型均为固定测试数据；不代表真实中转服务、登录、数据库或模型生成验收。未修改后端、依赖版本或现有本地服务。

## 中转模型实测

在「设置 → 模型接口」中，按中转服务对外提供的协议选择接口，不能仅凭模型名称判断。OpenAI 兼容地址应为基础路径（通常包含 `/v1`），平台追加 `/models` 和 `/chat/completions`；Claude 原生协议填写根地址，平台追加 `/v1/models` 和 `/v1/messages`。

输入个人 API Key → 获取模型并勾选（不支持列表时手动填准确 ID）→ 选择默认模型 → 保存 → 在游乐场发一条短消息 → 再进入 Skill 创建验证生成、预览和确认保存。Key 只在本地页面输入，不写进验证文档。

## 复现

使用项目锁定的依赖构建前端，构建时设置 `NEXT_PUBLIC_API_BASE_URL=http://localhost:13003`，以 13003 端口启动前端。Playwright 可安装在独立工具目录，避免变更项目依赖。从仓库根运行：

```sh
NODE_PATH=/path/to/playwright/node_modules node docs/verification/2026-09-07-select-controls/browser-check.cjs
```

脚本无需真实后端或 Key，会重写本目录的两张截图及 `result.json`。组件 API 对照 [Base UI Select 文档](https://base-ui.com/react/components/select) 和项目已安装版本的类型定义核对。
