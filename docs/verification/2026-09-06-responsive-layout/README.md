移除工作区主内容的 `max-w-7xl` 上限，主内容使用扣除桌面侧栏后的可用宽度。能力卡片改为按容器宽度自动排列，最小目标宽度 18rem；窄窗口允许单列收缩。设置表单等页面自身的阅读宽度限制保留。

本地热更新排查：当前 3000 端口服务来自同一工作目录，但返回的 Hub layout bundle 仍包含旧认证条件和旧品牌配色。仅本地使用、被 Git 排除的启动脚本已加入 `WATCHPACK_POLLING=1000`。独立开发服务开启该选项后，修改及还原测试副本中的品牌文案均触发热更新，无需浏览器刷新。脚本通过 `bash -n` 和 ShellCheck；运行中的本地服务需重启一次才能载入该环境变量。
