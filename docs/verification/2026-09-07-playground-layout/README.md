## 复现

使用项目锁定依赖，设置 `NEXT_PUBLIC_API_BASE_URL=http://localhost:13004` 构建前端并以 13004 端口启动。Playwright 安装在独立工具目录，无需修改项目依赖。在仓库根运行：

```sh
NODE_PATH=/path/to/playwright/node_modules node docs/verification/2026-09-07-playground-layout/browser-check.cjs
```

`APP_URL` 可覆盖页面地址。脚本仅使用测试数据，会更新本目录截图和结果文件。
