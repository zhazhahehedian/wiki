# 导航登录刷新与蓝色选中态验证

修复已登录页面在后台刷新 `/auth/me` 时被卸载的问题。初次加载仍等待认证，认证错误和会话过期仍隐藏受保护页面；登录页仍等待当前校验完成后跳转。品牌图标改为蓝底白图标，主导航及治理菜单使用浅蓝选中底色、蓝色文字和图标，桌面与移动导航共用样式。窗口自适应见[布局验证](../2026-09-06-responsive-layout/README.md)。

验证使用独立 WSL 前端副本与 Linux 依赖，未修改环境配置；本地启动脚本的轮询与预热调整不随本批次提交。

- Vitest：36 个测试文件、157 个用例通过，包括后台刷新时表单状态保留、401/过期处理、登录页旧缓存防跳转。
- `pnpm typecheck`、`pnpm build`（含 lint 和类型检查）通过。
- Chromium：推进浏览器测试时钟使默认 5 秒缓存过期，再点击设置/仪表盘，暂停认证响应，确认页面可操作、导航未卸载、无登录提示闪现，配置表单输入在响应完成后保留。认证返回 401 时仍跳转登录。
- 检查桌面主导航、治理选中态与移动侧栏，无横向溢出及浏览器运行错误。保留移动导航截图；桌面品牌与主导航见布局验证中的最终截图。

`browser-check.cjs` 使用模拟 HTTP 响应，不访问真实飞书、数据库或模型服务。前端构建时设 `NEXT_PUBLIC_API_BASE_URL=http://localhost:13003`，在 13003 端口启动后，使用可解析 `playwright` 的 Node 环境执行此脚本；自定义端口需同时设置 `APP_URL`。
