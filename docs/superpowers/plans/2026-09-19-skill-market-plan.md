# 内部能力市场与 Skill 复用

用户已确认沿现有注册中心实施内部市场、下载安装和基于已有 Skill 创建，不接外部市场、不在线执行 Skill。

## 实现约定

- `/hub/registry` 作为能力市场入口，保留 MCP/Skill 类型、搜索、部门和分页，增加场景快捷搜索；我的发布继续管理草稿。市场内容来自授权上线目录，不制造评分、下载量或精选数据。
- 市场详情使用独立页面和公开快照接口；即使 Owner/Admin 也不混入未上线草稿。展示说明、版本、发布者、文件、下载安装指引。
- “基于此创建”固定来源版本，服务端重新检查上线状态与访问权限。只读取来源，进入生成器内存草案，确认保存后才创建当前用户的新草稿，不修改原 Skill、不复制来源权限。
- 文本模板完整保留正文与附件。脚本、二进制、超出生成器限制的文件或无法保真的额外元信息不静默丢弃，提示下载原包使用；不执行文件。
- 保留原版本链接作为来源提示；改用新标识，原始标识冲突由已有保存接口拒绝。第一版不新增数据库 schema、不导入外部内容。

## 验证

- 后端：发布版本与权限选择、版本变化冲突、模板转换和附件完整性、不支持格式明确失败。
- 前端：市场筛选/分页、独立详情、模板加载/失败/重试、保存为新草稿；类型检查和生产构建。
- 浏览器：桌面和移动端浏览、文件预览、下载链接、模板进入生成器；本地模拟与真实外部服务验收分别记录。

## 实施结果

上述市场与复用功能已实现；后端包测试、前端 35 项相关测试、类型检查、生产构建及桌面/手机模拟接口浏览器流程通过。SQL 查询已重新生成，并已使用现有远程数据库完成只读连通性、迁移版本 15 及新目录 SQL 的实际执行检查；创建隔离测试库的完整写入集成测试尚未运行。Docker 不是远程数据库验证的前提。未迁移或修改业务数据库、未提交推送。详见 [验证记录](../../verification/2026-09-19-skill-market/README.md)。
