# 能力中心阶段 A · 平台骨架

范围（阶段 A 原始范围；后续游乐场后端授权见文末）：复用飞书登录、session/CSRF、Go/chi/repo、MinIO 和 River 基础设施；提供能力中心导航与页面骨架，关闭 KB/RAG 产品入口。本阶段不实现 B–F 的数据、审批、凭证、探测或模型调用。

依据：[能力中心设计](../specs/2026-09-04-capability-hub-design.md) §11–13。按 [AGENTS.md](../../../AGENTS.md) 执行；以下任务不强制提交或调用外部 Skill。

## 实施边界

- 生产 HTTP router 只暴露健康检查和认证入口，旧 KB/文档/会话 API 不再挂载；旧实现与测试暂留供迁移参考。
- 生产启动不创建旧 ingestion/sync/reconciler/agent，不检查旧 owner bootstrap 或 embedding 维度，不访问 LLM/Embedding/tokenizer。保留数据库、River schema、MinIO 初始化。
- 历史 migration 保持原样，阶段 A 不删除已有业务表或对象。全新数据库重放旧迁移仍需 pgvector 和 EMBEDDING_DIM；这与运行时不依赖 embedding 服务分开记录。表退役需单独迁移，不在启动时隐式删数据。
- OAuth 仅要求登录所需基础身份、邮箱与离线授权；删除 docx/sheet/bitable/wiki 产品权限要求。
- 前端根入口进入能力中心；旧 `/kbs` 及子路径重定向到新入口。深色侧栏、亮色内容、蓝色强调；可访问仪表盘、注册中心、游乐场、我的发布、设置。审核/审计等待阶段 C 的服务端 Admin 权限契约，不伪造客户端角色。
- 未实施的能力页明确显示暂未开放，不显示虚构统计、能力或可用的发布/调用按钮。
